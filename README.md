# DAA 2026/27 – Age Group Prediction 

Multi-class tabular machine learning pipeline for the **Data Analysis and Learning (DAA 2026/27)** competition: predicting a person's age group (`AGE_RANGE`, 16 brackets from `15-17` to `85+`) from health habits and socioeconomic survey features while maximizing **Macro F1**.

---

## Quick Start

### 1. Environment Setup
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 2. Run the Full Pipeline (End-to-End)
```bash
# Build processed features, train all 9 base models, stack, and create the next submission_vN.csv
make stack

# Or run everything including report tables and PNG figures
make all
```

### 3. Run Step-by-Step via CLI (`main.py`)
```bash
# 1. Clean data, engineer features, and freeze 5-fold StratifiedKFold splits
.venv/bin/python main.py preprocess

# 2. (Optional) Run LightGBM hyperparameter random search -> out/trials.json
.venv/bin/python main.py tune --trials 8

# 3. Train all 9 base models using the frozen CV folds
.venv/bin/python main.py train --all

# 4. Train Level-1 meta-learner + OOF-validated threshold optimization -> submissions/
.venv/bin/python main.py stack

# 5. Generate feature importance, anomaly diagnostics, clustering, and charts -> out/report/
.venv/bin/python main.py report --all
```

#### Advanced Training Options
- **Single or selected models:** `python main.py train --model lgb_tuned cat`
- **Hierarchical `<55` vs `55+` models:** `python main.py train --model hlgb hxgb hcat hrf`
- **Resumable per-fold training:**
  ```bash
  .venv/bin/python main.py train --model xgb --folds 0 1 2
  .venv/bin/python main.py train --model xgb --folds 3 4
  .venv/bin/python main.py train --model xgb --merge
  ```
- **Multi-seed averaging:** `.venv/bin/python main.py train --model xgb --seeds 1 2 3`
- **Force a new submission even if upstream files haven't changed:** `make -B stack`
- **Reset generated artifacts (`data/processed/`, `out/oof/`, `out/preds/`, `out/parts/`, `out/report/`):** `make clean`

### `data/` — Raw & Preprocessed Data

- **`data/raw/`** *(read-only competition CSVs)*:
  - `dataset_train.csv`: Training dataset (`10,962` rows, `237` columns including `AGE_RANGE`).
  - `dataset_test_X.csv`: Unlabeled test features (`3,655` rows, `236` columns).
  - `example_submission_10.csv`: Template defining the required submission schema (`RowId`, `AGE_RANGE`).
- **`data/processed/`** *(generated by `preprocess`, shared by all models)*:
  - `X_train.parquet` / `X_test.parquet`: Cleaned and engineered feature matrices.
  - `y_train.npy`: Training target vector (`AGE_RANGE` `0..15`).
  - `folds.npy`: Frozen `StratifiedKFold` fold assignment array ensuring every model and stacker trains/validates on identical partitions with zero leakage.
  - `meta.json`: Feature schema metadata (`cat_cols`, `num_cols`, sample counts, class count).

---

### `src/` — Modular Pipeline Source Code

| Module | Function |
|---|---|
| `src/__init__.py` | Marks `src/` as an importable Python package. |
| `src/config.py` | Loads `config.yaml` and automatically creates required output directories. |
| `src/preprocess.py` | Performs leakage-free preprocessing: infers column schema, constant-column filtering, and categorical vocabularies strictly from `X_train`; parses numeric-in-text and `HHMM` columns; adds MNAR missingness flags (`*_NA`, `*_SR`, `*_isna`), ordinal encodings, functional limitation severities, and life-stage/health/socioeconomic composites (`IS_RETIRED`, `IS_STUDENT`, `IS_EMPLOYED`, `HEALTH_RISK_SCORE`, `SES_STABILITY_SCORE`, etc.); freezes `folds.npy`; and audits train class balance and train/test missingness drift. |
| `src/tune.py` | Runs randomized LightGBM hyperparameter search on `X_train.parquet` and saves scored parameter sets to `out/trials.json`. |
| `src/train.py` | Unified CV trainer for any registered model (`--model`, `--all`, `--folds`/`--merge`, `--seeds`). Saves `(N, 16)` `float32` probability matrices to `out/oof/<model>.npy` and `out/preds/<model>.npy`. |
| `src/stack.py` | Level-1 stacking meta-learner (`LogisticRegression` on clipped log-probabilities) evaluated across the frozen `folds.npy`. Compares model subsets, performs **out-of-fold validation of per-class probability multipliers** (`scipy.optimize.minimize` Powell search) to boost Macro F1 only if it generalizes, and exports both `submissions/submission_v<N>.csv` (auto-incremented) and `submissions/submission_stack.csv` (latest copy). |
| `src/report.py` | Consolidates all report diagnostics and visualizations: LightGBM gain + SHAP feature contributions (`--importance`), supervised age-discrepancy anomalies (`--anomalies`), train-only Autoencoder / K-Means / DBSCAN profiling (`--unsupervised`), age-group demographic characterization (`--characterization`), and PNG plots (`--figures`). |

### `src/models/` — Unified Model Wrappers

Every model implements the same contract (`fit_predict(X_tr, y_tr, X_va, X_te, params, seed, meta) -> (val_probs, test_probs)`) with **strictly fold-local** imputation, scaling, and encoding:

| Module | Function |
|---|---|
| `src/models/__init__.py` | Package marker and `MODEL_REGISTRY` mapping model names to `fit_predict_*` functions, plus `get_model_params()` (loading `out/trials.json` for `lgb_tuned`/`hlgb`). |
| `src/models/base.py` | Shared fold-local preprocessing (`to_ordinal_arrays` with train-fold median imputation; `to_onehot_arrays` with train-fold imputation + `StandardScaler` + `OneHotEncoder`), `align_proba`, and `run_hierarchical` (`<55` vs `55+` survey routing). |
| `src/models/boosting.py` | Gradient boosted tree wrappers: `lgb_fe`, `lgb_tuned`, `xgb`, `cat`, and hierarchical variants `hlgb`, `hxgb`, `hcat`. |
| `src/models/trees.py` | Bagging tree wrappers: `rf` (Random Forest), `et` (ExtraTrees), and hierarchical `hrf`. |
| `src/models/neural_ordinal.py` | Linear, neural, and ordinal models: `lr` (Logistic Regression), `mlp` (Multi-Layer Perceptron), and `ord` (`OrdinalLGB` regressor projected to Gaussian class probabilities). |

### `out/`, `submissions/`, and `old/`

- **`out/oof/`**: Out-of-fold validation probability matrices `(10962, 16)` saved as `.npy` for every trained model (`lgb_fe.npy`, `lgb_tuned.npy`, `xgb.npy`, `cat.npy`, `rf.npy`, `et.npy`, `lr.npy`, `mlp.npy`, `ord.npy`, `hlgb.npy`, `stack_best.npy`). Used to compute CV scores and train the stacker without leakage.
- **`out/preds/`**: Test-set predicted probability matrices `(3655, 16)` averaged across the 5 CV folds, matching each file in `out/oof/`.
- **`out/parts/`**: Temporary per-fold `.npz` files created when running `train --folds ...` before `--merge`.
- **`out/trials.json`**: Scoreboard JSON storing LightGBM hyperparameter trials from `tune`.
- **`out/report/`**: Diagnostic CSV outputs (`feature_importance.csv`, `importance_by_age_group.csv`, `anomalies.csv`, `anomalias_caracterizacao.csv`, `autoencoder_erros.csv`, `kmeans_perfis.csv`, `dbscan_outliers.csv`, `caracterizacao_faixas.csv`) and `out/report/figs/` containing the 8 report PNG charts (`01_distribuicao_classes.png` through `08_caracterizacao_faixas.png`).
- **`submissions/`**: Leaderboard submission files. Every `stack` run creates a new incremented `submission_v<N>.csv` (e.g., `submission_v4.csv`) and updates `submission_stack.csv` as the latest copy.
- **`old/`**: Archived original scripts kept for historical reference (`pipeline.py`, `models2.py`, `tune_stack.py`, `new_models.py`, `stack_final.py`, `analysis.py`, `unsupervised.py`, `characterization.py`, `figures.py`, `fe2.py`, `hier.py`, `multiseed.py`, plus legacy `features*.pkl`).
